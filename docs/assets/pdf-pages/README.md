# 발표 자료 이미지 관리

루트 README의 이미지는 최종 발표 자료 `2026 KW해커톤 삼삼오오 월계함.pdf`의 16개 페이지를 원본 비율 그대로 렌더링한 PNG입니다. 슬라이드를 크롭하거나 재조합하지 않아 PDF가 바뀌어도 페이지 단위로 교체할 수 있습니다.

## 다시 만들기

Poppler가 설치된 환경에서 PDF 경로를 지정하고 실행합니다.

```bash
PDF="/path/to/2026 KW해커톤 삼삼오오 월계함.pdf"
pdftoppm -png -r 72 "$PDF" page
```

생성된 `page-01.png`부터 `page-16.png`까지를 이 폴더에 같은 이름으로 넣습니다. 렌더링 결과는 모두 1920×1080이어야 합니다.

README에서는 다음 페이지만 직접 사용합니다.

| 페이지 | 내용 |
|---:|---|
| 01 | 대표 화면 |
| 02 | 문제 장면 |
| 04 | 현장 조사 |
| 08 | 해결 구조 |
| 09 | 집주인 안내 등록 |
| 10 | 공개 안내 읽기 |
| 11 | 수정 메모 |
| 12 | A에서 B로 인계 |
| 13 | 외부인 제보 |
| 14 | 파일럿 계획 |

다른 페이지도 발표 흐름을 보존하고 이후 README 구성을 바꿀 수 있도록 함께 관리합니다. 이미지를 교체할 때는 README의 대체 텍스트와 이 표도 확인합니다.
