# 월계함

**건물에 남는 안내와 지금 사는 사람에게 닿는 경로를 합친 월계1동 생활 우편함**

> 사람은 바뀌어도, 건물은 남는다.

이 건물을 거쳐 간 사람이 남긴 것이 다음 사람의 첫날이 됩니다. 연락처를 주고받거나 대화방에 들어가지 않아도, 사람이 바뀔 때 이 건물에서 사는 데 필요한 맥락이 처음부터 다시 시작되지 않게 합니다.

| 핵심 가치 | 문장 |
|---|---|
| 남는다 | 사람이 바뀌어도 이 건물에서 살아가는 데 필요한 정보는 건물에 남는다. |
| 닿는다 | 지금 필요한 안내와 상황은 서로의 연락처를 몰라도 필요한 역할에게 전달된다. |

## 1. 출발점

### 현장에서 본 것

팀원이 사는 원룸에서 청소하는 분이 집주인에게 불편을 말했고, 집주인은 세입자에게 분리수거 안내를 카카오톡으로 한 명씩 보냈습니다. 현관에는 같은 내용의 A4가 이미 붙어 있었습니다.

정보는 건물에 있었습니다. 그 정보를 지금 사는 사람에게 닿게 하는 일은 집주인이 사람을 찾아 다시 해야 했습니다.

### 사람이 돌아가며 사는 동네

| 지표 | 값 | 출처 |
|---|---|---|
| 주택 중 다가구·다세대 비중 | 월계1동 31.8% (노원구 평균 9.6%) | 지역 통계 |
| 1인가구 | 10,320세대 중 5,157세대 | 행정안전부, 2026.8 |
| 월계1동 원룸 글 중 양도 글 | 253건 중 61건, 6·8·12·2월에 집중 | 에브리타임, 2024.1~2026.9 |
| 전국 청년가구 평균 거주기간 | 1.6년 | 국토교통부 2023년도 주거실태조사 |

서울시 모아센터와 노원구 클링크는 골목 관리와 무단투기 사후 단속을 맡습니다. 건물 안에서 누가 무엇을 알아야 하는지는 집주인과 세입자 사이에 남아 있습니다.

### 설문 20건 (2026.9.24, 자취 경험자 대상)

| 질문 | 전체 20명 | 월계1동 11명 |
|---|---|---|
| 같은 건물 사람에게 개인적으로 연락할 수 있다 | 0명 | 0명 |
| 입주민 단톡방이 없다 | 18명 | 9명 |
| 집주인 공지를 개인 카톡·문자로 받는다 (복수) | 12명 | 9명 |
| 분리수거를 현관 안내문으로 알았다 / 집주인 설명으로 알았다 (복수) | 13명 / 8명 | 7명 / 5명 |
| 최근 6개월 전하고 싶었지만 못 한 말이 있다 | 11명, 그중 9명은 그냥 참음 | 6명, 6명 모두 참음 |

주관식에는 소음, 흡연, 복도에 쌓인 짐, 음식물 냄새가 적혔고, "하고 싶은 말이 있어도 신변보호를 위해 참게 된다"는 답이 있었습니다. 편의표본이므로 숫자는 비율이 아니라 응답 수로 읽습니다.

## 2. 문제 정의

> 관리사무소 없는 월계1동의 작은 임대주거에서는 생활정보와 전달 경로가 사람과 임시 매체에 흩어져 있어, 사람이 바뀌면 필요한 생활맥락을 다시 이어야 한다.

| 불편 | 겪는 사람 | 반복되는 일 |
|---|---|---|
| 다음 사람이 다시 알아야 한다 | 집주인, 새 입주자 | 집주인이 이미 아는 분리수거·택배·설비 안내를 사람이 바뀔 때마다 다시 전한다 |
| 살아 본 경험이 사람과 함께 떠난다 | 거주자 | 살아 본 사람만 아는 정보를 남길 공통 자리가 없다 |
| 지금 생긴 일을 말할 길이 없다 | 거주자, 이웃, 청소 담당 | 소음·복도 적치·쓰레기를 보고도 말할 상대를 몰라 참는다 |

**How Might We**
어떻게 하면 월계1동에서 사람이 바뀌어도, 이 건물에서 살아가는 데 필요한 생활맥락이 다시 0부터 시작하지 않게 할 수 있을까?

생활맥락은 두 종류입니다. 계속 남아야 하는 것(기본 안내, 생활 팁)과 지금 필요한 사람에게 가야 하는 것(공지, 지금 생긴 상황).

## 3. 월계함이 하는 일

### 건물은 기억하고, 사람은 들어왔다 나가고, 공지는 현재 관계를 따라간다

| 붙는 곳 | 무엇 | 사람이 이사하면 |
|---|---|---|
| 건물 | 기본 안내, 생활 팁, 안내를 고친 결과 | 그대로 남는다 |
| 사람 | 계정, 입주 기록, 알림 설정, 내 제보 확인 | 이 건물과의 입주 관계만 끝난다 |
| 현재 입주 관계 | 공지 알림 | 관계가 끝난 사람에게는 가지 않는다 |

### 정보마다 쓰는 사람과 보는 사람

| 정보 | 쓰는 사람 | 보는 사람 | 판단하는 사람 |
|---|---|---|---|
| 기본 안내 | 집주인 | 누구나 | 집주인 |
| 공지 | 집주인 | 누구나, 멤버에게는 알림 | 집주인 |
| 생활 팁 | 멤버 (쓰지 않아도 된다) | 이 건물 멤버 | 신고가 들어오면 운영팀 |
| 수정 메모 "내용이 달라요" | 멤버 | 이 건물 멤버, 집주인 | 집주인 (반영 또는 기존 유지) |
| 제보 "집주인에게 알리기" | 누구나 | 집주인, 보낸 사람 | 집주인 (접수됨·확인함·처리 완료·처리가 어려움) |

### 들어오는 길과 나가는 길

- **현관 QR**은 누구나 엽니다. 로그인 없이 기본 안내와 공지를 읽고, 자주 쓰는 말 버튼과 보내기 두 번으로 집주인에게 알립니다.
- **가입코드**는 집주인이 계약할 때 한 번 건넵니다. 코드와 카카오 로그인으로 입주 기록이 생기면 팁, 메모, 공지 알림이 열립니다.
- **이사했어요**를 누르면 입주 관계만 끝나고 건물 정보는 남습니다.

제보는 이웃에게 직접 가지 않고 집주인을 거칩니다. 얼굴을 모르는 사람에게 직접 말하기 어려운 상황을 역할을 통해 전하기 위해서입니다. 화면은 접수와 해결을 나눠 보여주고, 처리 뒤 공지를 쓸지 안내를 고칠지는 집주인이 따로 정합니다.

### 함이와 크게 보기

함이는 건물에 붙은 우편함 마스코트입니다. 첫 진입, 빈 안내, 접수, 이사 때 다음 행동을 두 문장 안으로 알려줍니다. 처음 오셨나요는 앱 기능을 설명하지 않고 이 건물의 실제 안내를 한 장씩 보여줍니다. 크게 보기와 읽어주기는 모든 화면에서 한 위치에 고정하고 누구나 켜고 끕니다.

## 4. 한 건물의 한 사이클

| 단계 | 장면 |
|---|---|
| ① 건물이 생긴다 | 집주인이 카톡과 A4에 있던 안내를 월계함에 옮긴다. "분리수거함은 건물 뒤편"이라는 문장이 이제 ○○빌에 붙는다. 현관에 QR을 붙이고 가입코드가 적힌 입주 카드를 계약서와 함께 둔다 |
| ② A가 들어온다 | A는 현관 QR로 로그인 없이 쓰레기, 택배, 설비, 연락 안내를 읽는다. 가입하면 함이가 이 건물의 안내를 한 장씩 넘겨 보여준다 |
| ③ A가 산다 | 필요할 때 안내를 다시 보고 새 공지를 알림으로 받는다. 안내가 실제와 다르면 "내용이 달라요"를 남기고, 원하면 다음 사람을 위한 팁을 적는다 |
| ④ 지금 일이 생긴다 | 앞 건물 이웃이 건물 앞 쓰레기를 보고 QR을 찍어 두 번 누른다. 집주인에게 "○○빌 우편함에 쪽지가 왔어요"가 뜨고, 집주인은 확인함을 누른다. 보낸 사람은 확인 링크에서 상태를 본다 |
| ⑤ A가 떠난다 | A가 이사했어요를 누른다. A와 ○○빌의 입주 관계가 끝나고 공지는 더 이상 A에게 가지 않는다. 안내와 팁은 건물에 남는다 |
| ⑥ B가 들어온다 | B는 A를 모르고 연락처도 없다. 첫날 ○○빌에 남아 있던 안내와 A의 팁을 읽는다 |

## 5. 사용하는 사람

| 역할 | 지금 하는 일 | 월계함에서 하려는 일 |
|---|---|---|
| 집주인 | 새 세입자가 올 때마다 안내를 다시 보내고, 공지가 생기면 지금 사는 사람을 찾아 개인 카톡을 보낸다 | 건물의 기준 안내를 한 번 남기고, 필요할 때 지금 사는 사람에게 알린다 |
| 거주자 (A와 다음 입주자 B) | 처음 들어와 필요한 정보를 현관, 집주인, 부동산에서 따로 찾는다 | 이 건물에서 어떻게 사는지 첫날 알고, 알게 된 것이 있으면 다음 사람에게 남긴다 |
| 외부인 (이웃, 청소 담당) | 건물 앞 상황을 알아도 그 건물의 집주인을 모른다 | 사람을 찾거나 가입하지 않고 상황만 전하고, 나중에 상태를 본다 |
| 동 운영자 (주민자치회) | | 본선 이후 확장. 동 공지와 전화 제보 대리 접수를 맡는다 |

## 7. 주요 정책

| 영역 | 규칙 |
|---|---|
| 계정 | 카카오 고유 ID와 생성 시각만 저장한다. 이름, 전화번호, 호수는 받지 않는다 |
| 작성자 | 팁, 메모, 제보에 작성자를 표시하지 않는다. 글 내용으로 사람이 짐작될 수 있으므로 완전한 익명을 약속하지 않는다 |
| 가입코드 | 6자리, 암호화해 보관하고 집주인이 언제든 다시 본다. 재발급해도 기존 멤버는 유지된다. 현관 QR에는 코드를 넣지 않는다 |
| 재확인 | 가입 후 12개월에 "아직 사시나요?"를 묻는다. 14일 동안 답이 없으면 공지 알림과 쓰기만 멈추고 읽기는 남긴다. 입주 관계를 끝내는 것은 본인의 이사했어요뿐이다 |
| 제보 보관 | 처리 상태와 관계없이 접수 후 30일에 삭제한다. 25일째 접수됨이면 집주인에게 곧 사라진다고 표시한다 |
| 신고 | 팁과 메모만 신고할 수 있고 신고 1건으로 가려진다. 운영팀이 48시간 안에 판단하고, 복구된 글은 재신고로 가려지지 않는다 |
| 사람마다 쓸 수 있는 시간 | 이웃 제보는 두 번 누름 10초, 새 입주자의 가입과 안내 탐색은 3분, 집주인의 코드 전달은 1분, 공지 작성은 30초 |
