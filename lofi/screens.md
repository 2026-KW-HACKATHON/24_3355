# 화면과 흐름

상태: lofi 36장 반영(2026-09-25). 확정된 라우트 목록이나 Manyfast 동기화 결과가 아닙니다. 화면 흐름과 카드별 조건은 [board.html](board.html)이 기준이고, 이 문서는 LF ID와 파일의 대응, 규칙, 남은 상태를 정리합니다. 시트·입력 단계·완료 상태는 같은 LF ID 아래 관리합니다.

## End to end

집주인이 안내를 붙여넣어 남기고 입주 카드를 건넴 → A가 현관 QR로 공개 안내를 읽고 가입코드로 연결 → 처음 오셨나요로 첫날 시작 → 공지·팁·수정 메모 → 이웃이 자주 쓰는 말을 두 번 눌러 알림 → 집주인 알림·확인·처리 결과 → 이웃이 같은 QR로 재조회 → 집주인이 메모를 반영하거나 유지 → A의 이사 → B가 같은 안내와 A의 팁을 읽음.

## 관계와 상태 규칙

- 하단 탭은 거주자 `우리 건물 · 보낸 내용 · 내 정보`, 집주인 `건물 관리 · 받은 내용 · 설정`입니다. 동네 탭은 본선 이후입니다.
- 현관 QR로 열면 스플래시·소개·역할 선택·가입 없이 공개 건물 화면이 먼저 보입니다. 스플래시는 홈 화면 아이콘으로 열 때만 씁니다.
- 3D는 로딩 중·실패·‘동작 줄이기’에서 정적 그림으로 바뀌고, 건물명·안내·알리기를 먼저 쓸 수 있어야 합니다. 3D가 페이지 스크롤을 가로채지 않습니다.
- 권한은 로그인 여부가 아니라 이 건물과의 관계로 나눕니다. 공개 방문자와 다른 건물 거주자는 기본 안내·공지를 보고 상황을 보낼 수 있고, 생활 팁·수정 메모는 보지 않습니다.
- 가입코드는 집주인이 전달하는 6자리 영숫자 코드입니다. 휴대폰 인증번호나 소유권 증명이 아닙니다. 카카오 로그인도 거주 확인 절차가 아닙니다.
- 이미 연결된 사용자는 반복 가입을 생략합니다. 다른 건물로 전환할 때는 기존 관계 변경을 확인하고, 새 연결 실패 시 기존 관계를 유지합니다.
- 알림 선택은 가입 완료와 분리합니다. 가입 완료만으로 알림이 허용됐다고 표시하지 않습니다.
- 집주인에게 알리기는 자주 쓰는 말을 누르고 확인 시트에서 보내기까지 두 번입니다. 위치나 내용 덧붙이기와 직접 적기는 선택 경로입니다.
- 비회원 제보는 같은 기기에서 QR을 다시 찍으면 배너로, 다른 기기에서는 카카오톡에 보관한 링크(30일)로 재조회합니다. 나중에 로그인했다고 계정 목록에 자동으로 붙이지 않습니다.
- 집주인이 제보를 열기만 한 것은 확인이 아닙니다. `접수됨 → 확인함 → 처리 완료 또는 처리가 어려움`이며, 마지막 두 결과는 서로 다른 분기입니다.
- `처리 완료`는 집주인이 표시한 상태로 설명합니다. 실제 현장 문제 해결을 서비스가 확인한 것처럼 말하지 않습니다. 제보 원문은 공지나 안내에 자동으로 공개되지 않습니다.
- 수정 메모 제출은 기본 안내 변경이 아닙니다. 안내 저장이 성공한 뒤에만 메모가 ‘반영됨’이 되고, 유지하면 사유를 남깁니다.
- 계속 적용되는 규칙 변경은 공지만으로 끝내지 않고 기본 안내를 고칩니다. 공지는 기간이 지나면 내려갑니다.
- 이사로 입주 관계가 끝나도 기본 안내·생활 팁은 유지됩니다. B는 공개 안내를 먼저 보고 연결 후 팁을 읽습니다. 팁이 없어도 첫날은 성립해야 합니다.
- 거주 재확인 미응답과 명시적 이사를 구분합니다. 14일 무응답은 읽기만 가능한 상태이지 이사가 아닙니다. 데모 역할 전환으로 종료된 관계를 되살리지 않습니다.
- 콘텐츠 신고 처리는 운영자 업무입니다. 집주인의 안내 수정 검토와 구분합니다.

## 아직 그리지 않은 상태

가입코드 오류와 5회 실패 후 10분 대기, 로그인 취소 후 복귀, 가입 중 코드 변경, 기존 건물 관계 변경 확인, 작성 중 닫기, 저장 실패(입력 유지), 중복 전송, 전송 결과 불명확, 확인 링크 만료, 3D 로딩 실패, 메모 ‘기존 유지’ 사유 입력, 안내 저장 실패 시 메모 상태 유지, 거주 재확인 배너(house), 콘텐츠 신고 접수·가림(LF-19), 공지 만료 링크, 긴 건물 이름·긴 본문.

전송 결과가 불명확하면 성공으로 단정하지 않고 접수 확인·재시도 경로를 제공합니다.

## 확정 전 검토 항목

- 실제 집주인의 관리 권한 부여·확인 방식. 해커톤의 준비된 계정과 정식 서비스의 검증 흐름은 구분합니다.
- 안내 항목별 공개 범위. 출입 비밀번호·개인 연락처 같은 민감한 정보는 공개 예시에 넣지 않습니다.
- 제보 보관 기간·조회 만료, 코드·재확인 세부 정책은 Manyfast 정책 문서와 대조합니다. 이번 정리는 원격 명세를 갱신하지 않았습니다.
- 집주인 알림 채널: 시연은 앱 안 표시·웹 푸시(iOS는 홈 화면 추가 필요), 상용화는 카카오 알림톡(비즈니스 채널·템플릿 검수 필요).
- lofi에서 가정한 값(링크 30일, 집주인 한 줄 공개, 이사 후 보낸 내용 조회, 코드 변경 시 기존 거주자 유지, 재확인 예정월 위치)은 `board.html`의 ‘결정이 필요한 것’에 모읍니다.
- 약관·계정 탈퇴 등 실제 가입·운영에 필요한 세부 화면은 확정 전 별도 검토합니다.
- 처음 보는 사람의 과제 테스트(안내 찾기, 두 번 눌러 알리기, 재조회, 이사 후 B의 탐색)와 실제 기기 가독성 검증은 아직 수행하지 않았습니다.
